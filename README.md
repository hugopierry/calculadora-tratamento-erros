# Calculadora Python — Tratamento de Erros

Este projeto consiste em uma calculadora desenvolvida em Python com o objetivo de praticar e estudar o tratamento de erros utilizando `try` e `except`.

A calculadora realiza as quatro operações aritméticas: adição, subtração, multiplicação e divisão.

O foco principal não é apenas realizar os cálculos, mas também tratar entradas inválidas e exibir mensagens de erro no terminal, evitando que o programa seja interrompido inesperadamente.

## Tratamento de erros

O código contempla situações como:

- **ValueError:** ocorre quando o usuário informa valores inválidos, como letras ou textos que não podem ser convertidos em números.
- **TypeError:** utilizado para tratar operações incompatíveis entre tipos de dados.
- **Divisão por zero:** tratada por meio de uma condição que verifica se o divisor é diferente de zero antes de realizar a operação.
- **Operação inválida:** exibe uma mensagem quando o usuário escolhe um operador diferente dos disponíveis.

## Objetivo do projeto

Este exercício faz parte dos meus estudos de Python e tem como finalidade compreender melhor o funcionamento das estruturas de controle e do tratamento de exceções.

O código também serve como material de consulta para outros projetos, permitindo revisar conceitos e reutilizar o conhecimento adquirido durante o desenvolvimento.

## Tecnologias utilizadas

- Python 3
- `try` e `except`
- Estruturas condicionais (`if`, `elif` e `else`)
- Operadores aritméticos
- Entrada e saída de dados com `input()` e `print()`

## Aprendizados

Com este projeto, pratiquei a validação de entradas, o tratamento de exceções e a exibição de mensagens de erro, buscando tornar os programas mais seguros e evitar interrupções inesperadas durante a execução.
